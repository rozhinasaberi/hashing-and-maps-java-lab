# RojinaSaberi_COMP254Lab6

A COMP254 hashing and maps lab with a Streamlit tutor app that explains collisions, buckets, and load factor tradeoffs.

## What This Project Is About

This repository contains Java work on maps, abstract map design, chain hashing, and probe hashing. It now also includes a Streamlit tutor app that lets users experiment with keys and table sizes to see how collisions happen and why load factor matters for performance.

This is a **Java hashing and maps project with an AI tutor style Streamlit app**.

## What The Tutor App Teaches

- how keys are mapped into buckets
- why collisions happen in hash tables
- how load factor affects speed and memory tradeoffs
- how maps support fast lookup, insert, and update operations

## Project Structure

- `app.py` - Streamlit tutor app
- `requirements.txt` - Python dependencies for the tutor app
- `src/com/exercise1/rojina/saberi/`
- `src/com/exercise2/rojina/saberi/`

## Run The Streamlit App

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Open The Java Project

Import into Eclipse and run `Exercise1` or `Exercise2` from the `src/` folder.
