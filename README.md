# RojinaSaberi_COMP254Lab6

A COMP254 Java lab focused on maps, hashing, and performance experimentation.

## What This Project Is About

This lab implements several map-related structures and compares hashing behavior under different load factors. It includes abstract map foundations, sorted maps, chain hashing, probe hashing, and related support classes.

This is a **Java hashing and map data structures lab**.

## Exercises Included

- `exercise1` - hash map implementations and load factor timing experiment
- `exercise2` - additional lab exercise in the same project

## Main Concepts

- abstract map design
- sorted maps
- chained hashing
- probing-based hashing
- collisions and load factor tradeoffs

## Project Structure

- `src/com/exercise1/rojina/saberi/`
- `src/com/exercise2/rojina/saberi/`

## Open Or Run

Import into Eclipse and run `Exercise1` or `Exercise2` from the `src/` folder.
